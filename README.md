# 🏥 Chronic Disease Risk Predictor
Predicting Diabetes/Pre-diabetes risk using real-world NHANES (CDC) data.

## Project Structure
- `data/` — raw and processed datasets
- `notebooks/` — EDA and modeling notebooks
- `src/` — Python scripts
- `models/` — saved ML models
- `app/` — Streamlit deployment app
- `reports/` — plots and findings

## Tech Stack
Python | Pandas | Scikit-learn | XGBoost | SHAP | Streamlit
